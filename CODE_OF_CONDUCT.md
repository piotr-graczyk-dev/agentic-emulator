# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good intent, and keep discussions about the work.

Report unacceptable behaviour privately to the maintainer, Piotr Graczyk, through a
[private advisory](https://github.com/piotr-graczyk-dev/agentic-emulator/security/advisories/new):
only the maintainer sees it. Reports are handled confidentially.
